# Mentora

**Learn smarter. Practice better. Grow faster.**

Mentora is an AI-powered learning platform designed to make education more interactive, personalized, and engaging.

It enables educators to provide topics and learning materials, including **PDF and Word documents**, which can be used as context for generating intelligent, engaging quizzes with Generative AI.

## Core Features

* AI-powered quiz generation
* Topic-based learning and assessment
* PDF and Word document references
* Personalized learning experiences
* Multiple difficulty levels
* Instant scoring and feedback
* Student progress tracking
* Educator management tools

## Technology

* **Frontend:** React, TypeScript, Tailwind CSS
* **Backend:** Python, FastAPI
* **Database:** PostgreSQL
* **AI:** Generative AI & RAG
* **Collaboration:** Git & GitHub

## Vision

Mentora aims to make quality learning more **accessible, engaging, and intelligent** by combining modern education with Generative AI.

> **Mentora — Learn smarter. Practice better. Grow faster.**
